Catch up without replaying every write.

Tailstate is a C index for reconnecting workers. Each reader gets the latest change per key since its checkpoint, in sequence order. Deletions travel with the updates.

      Run it locally

      Extract the source and run the SQLite worker reconnect example with a C compiler, Make, and Python 3.

      tar -xzf tailstate.tar.gz
cd tailstate
make
python3 examples/reconnect.py

      Native benchmarks

      On Google’s Borg trace, compact Tailstate processed the hourly polling replay in 0.606 ms versus 6.023 ms for an ordered map. At one million keys and 10,000 logical readers, the map won the mixed replay. Both tests run in-process.
