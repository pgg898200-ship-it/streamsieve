# Hugging Face product pages

This bundle pairs the native RankFence and KthWake releases with their browser demos, installation instructions and benchmark evidence. It also repairs product links and descriptions on six existing Spaces.

| Space | Material in this bundle |
| --- | --- |
| RankFence | Browser replay, editable shard workbench, Python wheel, source archive, comparison data, agent guide and product card |
| KthWake | Interactive threshold timeline, C++17 header, compilable source archive, checksums and product card |
| EventFold | Direct downloads for the C header and benchmark archive, plus an explanation of the server-to-gateway link |
| SinceKit | Working demo link, license link and source-directory install step |
| Pulsefold | Direct links to the source archive and benchmark report on the Hub |
| Guardshift and Afterkey | Working license and demo links |
| EdgeChime | Stack placement, short description and link to the labeled replay dataset |

The archive has one directory per Space. Each path underneath a directory maps to the same path in that Space. Existing files outside those paths are preserved. The included revisions.json lists the reviewed Hub commit for each Space. Check the current commit before applying files to a Space that has since changed.

RankFence comes from [StreamSieve at 9107326](https://github.com/pgg898200-ship-it/streamsieve/tree/9107326cf0993e842c281d412cb276e83eb1c6a4). KthWake comes from [ChronoSieve at 7cca938](https://github.com/pgg898200-ship-it/chronosieve/tree/7cca93890a5bfa1e120f6aaabda8d1b8d7957b1f/companions/kthwake). Each archive includes its original license and data notices.
