Test your shard map

Paste a complete query as JSON. Supply one ranked ID list and one shard name per source. The replay compares pages read with and without the shard map, then checks both answers against exhaustive fusion. Your input stays in this browser.

This independent exact-integer replay checks at the end of each round of pages. The Python adapter also supports asynchronous arrivals and early closure of individual losing shards. Input limits are 64 streams and 20,000 entries.
