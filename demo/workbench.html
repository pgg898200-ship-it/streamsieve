Replay a search query

Four retrievers each return three document IDs. Both western retrievers put the same document first. Can the eastern shard still change the winner? Change a list or try your own query below. The replay runs in your browser.

Use one ordered list per retriever. Give two retrievers the same group if they can return the same document. Omit the groups to allow overlap across all lists.


    
The replay checks the winners against exhaustive fusion after simulating equal-sized page rounds. It accepts up to 64 streams and 20,000 IDs. The Python adapter also supports asynchronous pages and early closure of losing shards.
