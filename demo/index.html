Run it locally

Install the wheel, then give each ranked stream its document namespace. Here two western retrievers agree on a winner. The eastern retrievers can still produce pages.

from rankfence import PartitionFence

f = PartitionFence(["W", "W", "E", "E"], k=1)
for i, ids in enumerate([["a"], ["a"], ["b", "c"], ["c", "b"]]):
    f.push(i, ids)
assert f.ordered() == ("a",)

Where it pays off

On four local TCP producers, paging helped when extra hits were expensive. With fast producers, one full-window request per source won.

Expensive producer · RankFence p5045.5 ms
Expensive producer · one-shot p50106.4 ms
No delay · RankFence / one-shot p503.0 / 2.8 ms

12 TREC topics, three repeats. The expensive case adds 1 ms per request and 100 µs per hit. One-shot had the lowest p95 in all three tested scenarios.
