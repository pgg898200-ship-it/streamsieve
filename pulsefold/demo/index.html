Transition log

The first heartbeat arms every subscriber. A deadline that coincides with a heartbeat expires first. Receiving another heartbeat emits a recovery only for subscribers that went stale.

Run it on your fleet

Pulsefold is a single C++17 header. Feeds that use the same deadlines can share one policy, and a receiver can handle a group of expired readers in one callback. The scale test armed 1,048,576 feeds with 1,024 logical watches each at 34.27 MiB peak process memory.

Unzip the release and run make check live-check. Run make scale to reproduce the fleet test. The benchmark report includes real sensor timestamps and cases where other schedulers win.
